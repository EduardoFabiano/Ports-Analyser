# Ports Analyser

# Description:

this script is used to perform port scans and identify network vulnerabilities. Note: The use of VPNs, proxy servers, and private DNS can result in false positives, such as indications of "open ports." It is recommended to disable these services before running the scan, unless the user prefers to maintain digital security and avoid sending packets containing their public IP address.

# Installation:
```bash
git clone https://github.com/EduardoFabiano/Ports-Analyser
cd Ports-Analyser

Execute with:

python ports-analyser.py
```
